# Editorial menu artwork and logo policy — r17

This release integrates the supplied AI concept artwork as separate optimized images in real React interfaces. It does **not** publish a flattened mockup as the application.

- White/light surfaces use the existing canonical blue/red transparent logo.
- Dark surfaces use a derived white/red transparent version. The original pixel alpha, red GO geometry and red pixels are unchanged; only blue-dominant pixels become white.
- The merchant remains the lead brand. Its original transparent gold logo is unchanged.
- Generated concept prices, invented menu items, claims of popularity, public reviews and delivery promises are not copied. Featured prices and product details are always read from the current catalogue.
- Editorial imagery is representative, not verified photography of a served portion. Relevant captions remain visible. A crop manifest records original sources and native dimensions. No native 8K claim is made.
- Guest ordering, role/auth checks, camera permission, quote validation, LLM configuration, financial ledger and public catalogue are unchanged.
- The dark callout and light footer explicitly use separate logo variants; they are not selected based on operating-system theme.
